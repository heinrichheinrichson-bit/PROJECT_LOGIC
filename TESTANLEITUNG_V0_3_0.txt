PROJECT LOGIC v0.3.0 – EXAKTE TESTANLEITUNG

VORBEREITUNG
1. App und Chrome-Fenster schließen.
2. Aus diesem Update in das Projekt kopieren und vorhandene Dateien ersetzen:
   - lib
   - test
   - pubspec.yaml
   - CHANGELOG.md
3. In Git Bash im Projektordner ausführen:
   flutter clean && flutter pub get && flutter test
4. Erwartung: All tests passed!
5. App mit „Project Logic starten.bat“ starten.

TEST 1 – VERSION UND GRUNDFUNKTION
1. Unten muss „Version 0.3.0 · Entwicklungsstand“ stehen.
2. „Statistik“ ist jetzt auswählbar.
3. Dort muss zunächst „0 / 9 Rätsel abgeschlossen“ stehen.
4. Zurück zur Startseite.

TEST 2 – VERSTÄNDLICHER FORTSCHRITT
1. Neues Spiel → Binärpuzzle → Schwer → Rätsel 1.
2. Oben muss „0 von 29 Feldern gelöst“ stehen.
3. Ein freies Feld einmal antippen.
4. Erwartung: „1 von 29 Feldern gelöst“.
5. Dasselbe Feld zweimal weiter antippen, bis es wieder leer ist.
6. Erwartung: wieder „0 von 29 Feldern gelöst“.

TEST 3 – AUTOMATISCH SPEICHERN UND FORTSETZEN
1. In einem Rätsel mindestens drei freie Felder ausfüllen.
2. Mindestens sechs Sekunden warten.
3. Mit dem Zurück-Pfeil bis zur Startseite gehen.
4. Erwartung: Oben erscheint „Spiel fortsetzen“.
5. Darunter stehen Schwierigkeit, Rätselnummer und gespeicherte Zeit.
6. „Spiel fortsetzen“ öffnen.
7. Erwartung:
   - dieselben drei Felder sind gesetzt
   - der Timer läuft ungefähr ab dem vorherigen Stand weiter
   - der Fortschritt stimmt
8. Browser mit F5 neu laden und erneut prüfen.
   Der Spielstand muss weiterhin vorhanden sein.

TEST 4 – AKTIVES SPIEL WECHSELN
1. Zur Startseite zurückgehen.
2. Neues Spiel → Binärpuzzle → Mittel → Rätsel 2 öffnen.
3. Ein Feld setzen und zurückgehen.
4. „Spiel fortsetzen“ muss nun „Mittel · Rätsel 2“ anzeigen.
5. Beim Öffnen muss genau dieser neue Spielstand erscheinen.

TEST 5 – ABSCHLUSS UND BESTZEIT
1. Ein beliebiges Rätsel öffnen.
2. Käfer-Menü → „Sofort lösen“.
3. Erwartung: Gelöst-Dialog erscheint.
4. Zur Rätselauswahl zurückgehen.
5. Das gelöste Rätsel muss ein Häkchen und eine Bestzeit zeigen.
6. Zur Startseite zurückgehen.
7. „Spiel fortsetzen“ darf für das gelöste Rätsel nicht mehr erscheinen.
8. Statistik öffnen.
9. Erwartung:
   - 1 / 9 Rätsel abgeschlossen
   - passende Schwierigkeit zeigt 1 von 3
   - die Prozentzahl beträgt 33 %

TEST 6 – BESTZEIT BLEIBT BESTZEIT
1. Dasselbe gelöste Rätsel erneut öffnen.
2. Mindestens zwei Sekunden warten.
3. Käfer-Menü → „Sofort lösen“.
4. In der Rätselauswahl muss weiterhin die kleinere der beiden Zeiten stehen.

TEST 7 – NÄCHSTES RÄTSEL
1. Rätsel 1 per Testmodus lösen.
2. Im Dialog „Nächstes Rätsel“ drücken.
3. Rätsel 2 muss geöffnet werden.
4. Ein Feld setzen, zurück zur Startseite.
5. „Spiel fortsetzen“ muss Rätsel 2 nennen.

TEST 8 – NEUSTART
1. Einen gespeicherten Spielstand öffnen.
2. Oben auf das Neustart-Symbol drücken.
3. Erwartung:
   - alle Spielereingaben verschwinden
   - Timer beginnt wieder bei 0:00
   - Fortschritt steht bei 0 von X
4. Zur Startseite und wieder fortsetzen.
5. Auch dort muss der zurückgesetzte Zustand erscheinen.

TEST 9 – RESPONSIVES LAYOUT
1. Chrome auf ungefähr Handybreite verkleinern.
2. Startseite, Statistik, Rätselauswahl und Spielfeld prüfen.
3. Es dürfen keine gelb-schwarzen Überlaufstreifen auftreten.
